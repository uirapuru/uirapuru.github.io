Privacy Policy — Print Plugin

Last updated: 22 August 2026

Print Plugin is a plugin for ATAK-CIV developed by Grzegorz Kaszuba ("the developer").

The plugin exports the current ATAK map view to a PDF or PNG file.

Data the plugin collects

None. The plugin does not collect, transmit, or share any personal or device data.

Specific facts behind that statement:

  • The plugin declares no Android permissions of its own.
  • The plugin contains no networking code. It opens no connections and sends nothing to

the developer or to any third party.

  • The plugin contains no analytics, advertising, or tracking libraries.
  • The plugin does not use the advertising identifier.

Files the plugin creates

Exported PDF and PNG files are written to storage on the device, in the cache directory of

the ATAK application. These files stay on the device. The plugin does not upload them.

You may delete them at any time through ATAK or a file manager.

Data handled by ATAK

Print Plugin runs inside ATAK-CIV and renders what the host application displays: map tiles,

markers, and drawings. Handling of that data is governed by ATAK-CIV and by the map and server

providers you configure there. This policy covers only Print Plugin.

Distribution through Google Play

Google Play collects installation and crash data on its own terms, independently of the plugin.

See the Google Play Services privacy policy.

Children

The plugin is intended for users aged 18 or over. It is not directed at children.
