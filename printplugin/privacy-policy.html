Privacy Policy — Print Plugin

Last updated: 18 November 2026 (version 1.0.1)

Print Plugin is a plugin for ATAK-CIV developed by Grzegorz Kaszuba ("the developer"). The plugin exports the current ATAK map view as A4 sheets in a PDF or PNG file.

Data the plugin collects

None. The plugin does not collect, transmit, or share any personal or device data.

Specific facts behind that statement:

  • The plugin declares no Android permissions of its own and does not ask for storage access.
  • The plugin contains no networking code. It opens no connections and sends nothing to the developer or to any third party.
  • The plugin contains no analytics, advertising, or tracking libraries.
  • The plugin does not use the advertising identifier.
  • The plugin has no user account, no login, and never asks for an email address.

Files the plugin creates

While an export is being prepared, the sheet images sit in the cache directory of the ATAK application. The plugin removes them the next time it starts.

The finished PDF or PNG file is written only to the location you pick in the Android save dialog. The file stays where you saved it. The plugin does not upload it.

The start screen

The Print Plugin icon in the phone's app menu opens a start screen. To show whether ATAK-CIV is installed, the screen checks for that one app on the device. It reads no other information about installed apps.

Data handled by ATAK

Print Plugin runs inside ATAK-CIV and renders what the host application displays: map tiles, markers, and drawings. Handling of that data is governed by ATAK-CIV and by the map and server providers you configure there. This policy covers only Print Plugin.

Distribution through Google Play

Google Play collects installation and crash data on its own terms, independently of the plugin. See the Google Privacy Policy.

Children

The plugin is intended for users aged 18 or over. It is not directed at children.
