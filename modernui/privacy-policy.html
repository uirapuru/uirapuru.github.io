Privacy Policy — Modern UI

Last updated: 18 November 2026 (version 0.13.0)

Modern UI is a plugin for ATAK-CIV developed by Grzegorz Kaszuba ("the developer").

The plugin replaces the ATAK toolbar with a compact portrait interface. Almost every icon starts a function that ATAK already has. The plugin runs entirely on the device.

Data the plugin collects

None. The plugin does not send any personal or device data to the developer or to any third party.

Specific facts behind that statement:

  • The plugin declares no Android permissions of its own.
  • The plugin contains no networking code. It opens no connections and sends nothing to the developer or to any third party.
  • The plugin contains no analytics, advertising, or tracking libraries.
  • The plugin does not use the advertising identifier.
  • The plugin has no user account, no login, and never asks for an email address.

Information the plugin reads and shows

While the new interface is on screen, the plugin reads the following from ATAK and from the phone, on the device, and shows it on screen:

  • your own position as ATAK knows it — coordinates, altitude, heading, speed and GPS accuracy — and your callsign, in the location field,
  • whether ATAK is connected to each TAK server you configured,
  • the mobile signal level, whether a SIM card is ready, and whether airplane mode is on,
  • the number of unread chat messages that ATAK already shows on its own contacts button,
  • the list of ATAK tools and the toolbar buttons of other installed plugins (name and icon).

These values are shown and then discarded. They are not stored, logged, or sent anywhere. The plugin does not read message contents, contact details, your phone number, or SIM identifiers.

ATAK settings the plugin can change at your request

  • Turning a TAK server connection on or off from the server list.
  • The ATAK setting „Hide my current location”, from the location field. ATAK then stops sharing your position with others.
  • Setting your position by hand, which opens the ATAK tool for that.
  • The screen orientation.

The plugin changes these settings only when you choose the matching item.

Data the plugin stores

In the ATAK settings on the device the plugin stores: the selected interface (new or standard), the screen orientation from before the new interface was first turned on, the positions of the bars, the status box and the ATAK windows, the tools you placed on your tool bar, and your themes.

When you export a theme, the plugin writes it as a JSON file to atak/tools/modernui/themes on the device. When you import themes, it reads the files you pick. A theme file holds colours, transparency and text size only.

The start screen

The Modern UI icon in the phone's app menu opens a start screen. To show whether ATAK-CIV is installed, the screen checks for that one app on the device. It reads no other information about installed apps.

Data handled by ATAK

Modern UI runs inside ATAK-CIV. What ATAK does with your position, chat and map data is governed by ATAK-CIV and by the TAK servers you configure there. This policy covers only Modern UI.

Distribution through Google Play

Google Play collects installation and crash data on its own terms, independently of the plugin. See the Google Privacy Policy.

Children

The plugin is intended for users aged 18 or over. It is not directed at children.
