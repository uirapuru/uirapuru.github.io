Privacy Policy — Modern UI

Last updated: 28 September 2026

Modern UI is a plugin for ATAK-CIV developed by Grzegorz Kaszuba ("the developer").

The plugin replaces the ATAK toolbar with a compact portrait interface. It adds no features of its own: every icon starts a function that ATAK already has. The plugin runs entirely on the device.

Data the plugin collects

None. The plugin does not collect, transmit, or share any personal or device data.

Specific facts behind that statement:

  • The plugin declares no Android permissions of its own.
  • The plugin contains no networking code. It opens no connections and sends nothing to the developer or to any third party.
  • The plugin contains no analytics, advertising, or tracking libraries.
  • The plugin does not use the advertising identifier.
  • The plugin has no user account, no login, and never asks for an email address.

Information the plugin reads to show status

The plugin shows three status indicators. To draw them it reads, on the device and only while the new interface is on screen:

  • whether ATAK is connected to the TAK servers you configured in ATAK,
  • whether ATAK has a GPS position and how accurate it is, in metres,
  • the mobile signal level, whether a SIM card is ready, and whether airplane mode is on.

These values are shown on screen and then discarded. They are not stored, logged, or sent anywhere. The plugin does not read your position coordinates, phone number, or SIM identifiers.

Settings the plugin stores

The plugin writes two entries into the ATAK settings on the device: which interface is selected (new or standard) and the screen orientation you had before the new interface was first turned on, so it can be restored. It also switches the existing ATAK setting that forces portrait orientation. It creates no files and no database.

Distribution through Google Play

Google Play collects installation and crash data on its own terms, independently of the plugin. See the Google Play Services privacy policy.

Children

The plugin is intended for users aged 18 or over. It is not directed at children.
