Privacy Policy — SniperKIT

Last updated: 26 September 2026

SniperKIT is a long-range ballistic calculator with a built-in map, developed by Grzegorz Kaszuba ("the developer"). It is a standalone Android app and does not need ATAK.

Data the developer collects

None. SniperKIT sends nothing to the developer. It has no user account, no login, no analytics, no advertising, and no tracking libraries. It does not use the advertising identifier.

Connections the app opens

The map and the terrain need data from the internet. Each request goes directly from your device to the server listed below. Every server receives your IP address and the map area you are looking at, because that is what the request asks for. Each server handles that data under its own terms.

  • Base map tiles: OpenStreetMap (tile.openstreetmap.org).
  • Satellite layer, when you switch the map source: Google map tile servers (mt0–mt3.google.com).
  • Terrain elevation tiles: the Terrarium data set on Amazon Web Services (elevation-tiles-prod.s3.amazonaws.com).
  • Map label fonts: MapLibre (demotiles.maplibre.org).

Data you send to other devices

SniperKIT can send the shooter position, the observation post, targets, the range card, and the observation sector as Cursor on Target (CoT) events. The events go to one of two places:

  • UDP multicast on your local network (group 239.2.3.1, port 6969 by default). The packets have a time-to-live of 1, so routers do not forward them beyond the local network.
  • A TCP address that you enter in the connection settings. An empty address turns TCP sending off.

The events are not encrypted. Any device on the same local network can read multicast events. The developer never receives them. Where the events go after that depends on the receiving application.

Location

The current version does not read the device's location and does not ask for the location permission. The shooter position is the centre of the map when the app starts. A future version may use GPS; this policy will be updated before that version is released.

Data stored on the device

  • Rifle profiles and app settings, in the app's private storage.
  • CoT events that have not been sent yet. They are sent when the connection returns.
  • Cached map and terrain tiles.
  • The shot journal, if you use it.

Map objects (targets, observation post) are kept in memory only and disappear when the app closes. Uninstalling the app removes all of the data above. Exporting profiles, a range card, or a CSV file creates a copy in the location you choose; that copy stays after uninstalling.

Distribution through Google Play

Google Play collects installation and crash data on its own terms, independently of the app. See the Google Privacy Policy.

Children

SniperKIT is intended for users aged 18 or over. It is not directed at children.
