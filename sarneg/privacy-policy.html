Privacy Policy — Sarneg

Last updated: 15 September 2026

Sarneg is a plugin for ATAK-CIV developed by Grzegorz Kaszuba ("the developer").

The plugin encrypts and decrypts the numbers inside a message with the SARNEG substitution cipher. A key word of ten distinct letters replaces each digit with a letter. The plugin runs entirely on the device.

Data the plugin collects

None. The plugin does not collect, transmit, or share any personal or device data.

Specific facts behind that statement:

  • The plugin declares no Android permissions of its own.
  • The plugin contains no networking code. It opens no connections and sends nothing to the developer or to any third party.
  • The plugin contains no analytics, advertising, or tracking libraries.
  • The plugin does not use the advertising identifier.
  • The plugin has no user account, no login, and never asks for an email address.

Files the plugin creates

None. The plugin writes nothing to storage — no files, no database, and no entry in the ATAK shared preferences.

The key word and the message text exist only in the memory of the running process. The key word is discarded when you confirm the "new" button or when ATAK unloads the plugin. The input field and the result are cleared by any of six events: closing the result window, the countdown in the result window reaching zero, pressing "copy", pressing "send to chat", closing the plugin panel, and ATAK going to the background.

The plugin log records event names only. It never records message text or the key word.

The Android clipboard

Pressing "copy" puts the result into the system clipboard, which lives outside the plugin and is readable by the Android system and, on older Android versions, by other applications. The plugin clears that clipboard entry 60 seconds after the copy. Until then the text is on the clipboard and you may paste it yourself into any application.

Messages you send to chat

Pressing "send to chat" hands the text to ATAK, which opens its own recipient picker. From that point the message is an ATAK chat message. Where it goes depends on how you configure ATAK — on the TAK server you connect to and the contacts you pick. That handling is governed by ATAK-CIV and by the servers you configure there. This policy covers only Sarneg.

Chat messages the plugin reads

While a key word is set, the plugin watches incoming ATAK chat messages and shows a notification when a message looks encrypted with that key word. The check happens on the device. The message is not stored, and neither the message nor the key word is placed in the notification.

What the cipher does not do

SARNEG is a substitution cipher for digits, not modern cryptography. It hides numbers from someone who does not know the key word. It is not resistant to cryptanalysis, and it is not a security control you should rely on to protect data whose disclosure would cause harm.

Distribution through Google Play

Google Play collects installation and crash data on its own terms, independently of the plugin. See the Google Play Services privacy policy.

Children

The plugin is intended for users aged 18 or over. It is not directed at children.
