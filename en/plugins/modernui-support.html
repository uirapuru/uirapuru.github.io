Modern UI — Support

Contact, bug reports, privacy, frequently asked questions and known issues for Modern UI.

Contact

Send questions and reports by email to kontakt@taklab.eu. I reply within a few days, in English or Polish.

How to report a bug

Send an email with the subject „Modern UI – bug” and include:

  • the plugin version, for example „Version 0.13.0 (build 20)”; it is shown on the start screen opened by the Modern UI icon in the phone's app menu, and under More → About,
  • the ATAK-CIV version; you will find it in Android settings under Apps → ATAK,
  • the phone model and Android version,
  • the screen orientation in which the bug appears: portrait or landscape,
  • the steps that lead to the bug and the result you expected,
  • a screenshot. For a plugin that changes how ATAK looks, a screenshot shows more than a description.

Without the plugin and ATAK-CIV versions the bug cannot be reproduced. The plugin sends no reports by itself, so your email is the only source of information about the bug.

Privacy

The plugin collects no data and sends nothing over the internet. It has no networking code, no analytics libraries and no adverts. It declares no Android permissions.

On screen the plugin shows data it reads from ATAK and the phone: your own position (coordinates, altitude, heading, speed, GPS accuracy) with your callsign, the connection state of your TAK servers and the mobile network state. It stores and sends none of it. It does not read your phone number or message contents.

At your request the plugin turns a TAK server connection on or off and switches the ATAK setting „Hide my current location”.

In the ATAK settings the plugin stores the selected interface mode, the screen orientation, the tool bar layout, bar and window positions, and themes. A theme goes to a file in atak/tools/modernui/themes only when you export it yourself.

Frequently asked questions

How do I go back to the standard ATAK look?

Choose More → Standard ATAK interface. The plugin restores the ATAK toolbar, the system bar, the normal windows and the screen orientation from before it was turned on. The plugin button on the ATAK toolbar turns the new interface back on.

The Modern UI icon in the phone menu does not change ATAK. Why?

The icon only opens a start screen with instructions and the version. The plugin works inside ATAK: once loaded from the Plugins menu, the new interface turns on by itself.

Which ATAK versions does it run on?

ATAK-CIV 5.5, 5.7 and 5.8. One package runs on all three.

A bar or window ended up in an awkward place. How do I restore it?

Choose More → Reset window positions. Bars and windows return to their default places.

All the buttons are gone. What happened?

„Map only” mode is on. The button in the bottom right corner brings the buttons back.

How do I put a tool or another plugin's button on the bar?

Choose More → Customize. The bar holds up to 6 tools. Set the order with the arrows.

How do I switch ATAK to landscape?

Choose More → Portrait / landscape. The plugin remembers the choice after ATAK restarts.

How do I join the test?

The plugin is in closed testing on Google Play. Email me the Gmail address you use in the Play Store and I will add it to the tester list.
