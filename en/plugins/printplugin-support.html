PrintPlugin — Support

Contact, bug reports, privacy, frequently asked questions and known issues for PrintPlugin.

Contact

Send questions and reports by email to uirapuruadg@gmail.com. I reply within a few days, in English or Polish.

How to report a bug

Send an email with the subject „PrintPlugin – bug” and include:

  • the plugin version line from the start screen, for example „Version 1.0.1 [5.8.0] (build 8)”; the Print Plugin icon in the phone's app menu opens the start screen,
  • the ATAK-CIV version; you will find it in Android settings under Apps → ATAK,
  • the phone model and Android version,
  • the settings from the „Map export” window: format, background, MGRS grid, scale and topographic sheet,
  • the steps that lead to the bug and what you expected to happen,
  • a screenshot of the preview, or the output file if the export succeeded.

Without the plugin and ATAK-CIV versions the bug cannot be reproduced. The plugin sends no reports by itself, so your email is the only source of information about the bug.

Privacy

The plugin collects no data and sends nothing over the internet. It has no networking code, no analytics libraries and no adverts. It does not ask for storage access.

Sheets being exported sit in ATAK's temporary directory and are removed the next time the plugin starts. The finished file goes only to the place you pick in the system save dialog.

Frequently asked questions

Where is the Print button?

On the ATAK toolbar. If it is not there, open the toolbar menu (the gear icon) and choose „All tools & plugins”.

The Print Plugin icon in the phone menu does not print a map. Why?

The icon only opens a start screen with instructions and the version. Exporting works only inside ATAK, with the Print button.

Which ATAK versions does it run on?

ATAK-CIV 5.5, 5.7 and 5.8. One package runs on all three.

How do I print a map to scale so I can measure with a ruler?

Choose a fixed scale, for example 1:25,000, and the PDF format. When printing, set A4 paper and 100 % size, without fit to page. After printing, measure the scale bar with a ruler and compare it with its label.

Why do I get several sheets?

At a fixed scale, a view that does not fit on one A4 sheet is split into sheets numbered row by row from the top left. „Fit to view” always gives one sheet.

Does the plugin work offline?

Yes. It prints the tiles ATAK has cached. With no tiles, choose „White background”: the sheet will show objects and the MGRS grid.

How do I join the test?

The plugin is in closed testing on Google Play. Email me the Gmail address you use in the Play Store and I will add it to the tester list.

Known issues and limitations

SymptomCauseWhat to do
Nothing happens after pressing OK.The map shows the whole globe.Zoom in and export again.
Part of a sheet is blank while the grid and labels are in place.ATAK has no base map tiles for that area.Pan the map over the whole area so ATAK downloads the tiles, or choose „White background”.
The message „Turn off map tilt”.With a tilted map the scale is not uniform.Turn off 3D view and export at a fixed scale again.
A fixed-scale export is refused.The view needs more than 16 sheets.Shrink the view or choose 1:50,000 or 1:100,000.
The message „Export is already being prepared”.The plugin runs one export at a time.Wait for the preview.
The printout has a different scale from the label on the sheet.The printer fitted the sheet to the page.Print at 100 % size, without fit to page.
The message „System save dialog is unavailable”.Android did not open the file picker.Restart ATAK and export again.
With „Fit to view” there is a white strip beside the map.The phone screen is taller than an A4 sheet and the plugin never stretches the map.This is intended. Choose a fixed scale to fill the sheet.
The plugin speaks a different language from ATAK.The plugin follows the phone language. ATAK does not allow a separate per-app language.Change the phone language. Polish and English are supported.
